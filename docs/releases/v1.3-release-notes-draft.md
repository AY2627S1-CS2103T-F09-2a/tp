# Poco Book v1.3 — release notes draft

**Preparation only: publish after the final integration and documentation gates in
[v1.3 preparation](v1.3-preparation.md) pass.**

Poco Book adapts AddressBook Level 3 for independent tutors managing student records and outstanding fees.

## Changes from AddressBook Level 3

- Store a student's guardian name and guardian phone, together with an optional outstanding fee, in local JSON.
- Show outstanding amounts on student cards as Singapore-dollar amounts with two decimal places.
- Use `fees` to list students with outstanding fees and `setoutstanding INDEX AMOUNT` to replace or clear an amount.
  Setting an amount to zero clears the fee; students disappear from a fees-only list when cleared.
- Reject invalid displayed indexes and invalid fee amounts without changing the current records or list.
- Keep data, preferences and logs beside the executable JAR, even when it is launched from another directory
  (pending merge of the sandbox preparation PR).
